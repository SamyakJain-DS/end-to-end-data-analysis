# 🌐 Frontend UI (Streamlit)

We developed an interactive web application using **Streamlit** to allow users to explore insights on electronic devices with ease.

## 🖱️ Key Features
- Fully interactive website where user can select which category to analyse.
- Analyze devices based on **brand**, **price range**, and **category** (e.g., laptops, smartphones)
- Visualize insights via **bar charts**, **line plots**, and **tables**
- Made beautifully animated buttons to make input intuitive
- Front-end powered by **Flask APIs** that fetch data directly from the OLAP warehouse

## 🚀 Why Streamlit?
- Minimal boilerplate and fast deployment
- Seamless integration with Python data workflows
- Strong support for interactivity and visualization

> 📈 Example: A user can select choose to view the market analysis of all laptop devices as per our scraped data.

## 🌍 Deployment
- Hosted on **Streamlit Community Cloud**, making it publicly accessible
- Linked to GitHub for easy updates and version control

✅ **Outcome**: A production-ready, interactive dashboard that empowers non-technical users to gain insights from the data effortlessly.
